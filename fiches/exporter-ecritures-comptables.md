# Exporter les écritures pour l’expert-comptable

## Symptôme

L’expert-comptable du client demande les ventes du mois ou de l’année dans un fichier.

## Étapes

1. Ouvre **Comptabilité → Exports**.
2. Choisis la période : mois, trimestre ou exercice complet.
3. Choisis le format :
   - **FEC** pour un exercice complet, au format attendu par l’administration fiscale ;
   - **CSV** pour une période plus courte ou un import dans le logiciel de l’expert-comptable.
4. Vérifie que les comptes de vente sont renseignés dans **Comptabilité → Plan comptable**. Sinon, l’export signale les lignes concernées.
5. Clique sur **Générer**, puis sur **Télécharger** quand le fichier est prêt.

## Vérification

Le fichier téléchargé contient une ligne par écriture. Le total des ventes de l’export est égal au total hors taxes affiché dans **Factures** pour la même période, avoirs déduits.
